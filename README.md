# Interactive Sorting Algorithms Visualizer

## About the Project

The Interactive Sorting Algorithms Visualizer is a web-based application that helps users understand how different sorting algorithms work.

It displays a collection of bars representing numbers and shows how their positions change as the sorting algorithm runs. This makes it easier to understand the sorting process step by step instead of just reading the theory.

I developed this project as part of my college assignment using HTML, CSS, and JavaScript.

## Features

* Visual representation of sorting algorithms using bars.
* Generate a new set of random numbers.
* Watch the sorting process through animations.
* Adjust the speed of the animation.
* Compare different sorting algorithms.
* Reset the visualization and try again.

## Algorithms Included

* **Bubble Sort:** Repeatedly compares adjacent elements and swaps them when they are in the wrong order.
* **Selection Sort:** Finds the smallest element and places it in the correct position.
* **Insertion Sort:** Builds the sorted list one element at a time.
* **Merge Sort:** Divides the array into smaller parts, sorts them, and merges them.
* **Quick Sort:** Uses a pivot to divide the array into smaller sections and sort them.

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open the `index.html` file in your browser.
4. Alternatively, use the Live Server extension in VS Code.

No additional libraries or installations are required.

## How to Use

1. Open the application in your browser.
2. Generate a random array of numbers.
3. Select the sorting algorithm you want to visualize.
4. Adjust the animation speed if the option is available.
5. Start the visualization.
6. Watch how the elements move into sorted order.
7. Generate another array to experiment with different inputs.

## Time Complexity

| Algorithm      | Best Case  | Average Case | Worst Case |
| -------------- | ---------- | ------------ | ---------- |
| Bubble Sort    | O(n)*      | O(n²)        | O(n²)      |
| Selection Sort | O(n²)      | O(n²)        | O(n²)      |
| Insertion Sort | O(n)       | O(n²)        | O(n²)      |
| Merge Sort     | O(n log n) | O(n log n)   | O(n log n) |
| Quick Sort     | O(n log n) | O(n log n)   | O(n²)      |

*Bubble Sort has O(n) best-case time when implemented with an optimization that detects when no swaps are needed.*
